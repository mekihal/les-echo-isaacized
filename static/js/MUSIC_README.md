# Музыкальная система Les Echo

Музыка реализована отдельным Web Audio движком в `music.js`; MIDI-derived event data для одиннадцати композиций хранится в `music-data.js`.

## Поведение

- Девять региональных тем выбираются по `zone.id` из серверной конфигурации.
- Тема босса включается, когда поддерживаемый босс оказывается в радиусе 640 мировых единиц от игрока.
- При выходе из радиуса босса возвращается тема текущего региона.
- Региональный crossfade: 5,4 секунды; возврат после босса: 4,8 секунды; переход на тему босса: 3 секунды.
- При быстро сменяющихся целях переход переориентируется от текущего слышимого состояния, а не сбрасывает громкость активной дорожки.
- Музыка намеренно тихая (master gain 0,135), без MIDI-перкуссии, с мягким синтезом и небольшим реверберационным хвостом.
- Музыкальный контекст разблокируется первым пользовательским жестом согласно ограничениям autoplay браузера.
- Клавиша N синхронно включает/выключает SFX и музыку; состояние сохраняется в `localStorage` (`echo_mute`).

## Добавление или замена композиций

Исходные партитуры — MIDI Type 1 с отдельными партиями. Данные в `music-data.js` — компактное deflate-представление MIDI-событий; порядок треков и идентификаторы заданы в начале `music.js`. Если меняется число треков или их порядок, синхронно обновляй массив `keys` в `decodePack()` и соответствие идентификаторов в `ZONES` / `BOSSES`.

## Технические детали

Нет сторонних библиотек и внешних аудио-URL. Браузер декодирует локальный deflate-пакет и планирует ноты с небольшим look-ahead через Web Audio API. Для каждого MIDI program используется мягкий синтезаторный тембр; это облегчённая игровая озвучка MIDI, а не точное воспроизведение GM SoundFont.
